# Commit messages

- Subject: one line, imperative, <72 chars. Conventional prefix (`feat:`, `fix:`, `chore:`...). This does the work.
- Body: only when it earns it. Load-bearing bullets a future reader needs (a non-obvious bug, a gotcha, a why). No paragraphs, no vibe lines, no "process verdict" essays.
- When in doubt, ship subject-only. Older commits in this repo (`feat: readme`, `fix: build config`) are the target register.
